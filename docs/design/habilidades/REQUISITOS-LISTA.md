# Requisitos: lista de tipos (proposta para o dono escolher)

Pedido de 23/11/2026 (literal no PEDIDOS.md): requisitos para usar habilidade, arma e item, e para evoluir e transformar. "Requisitos" é o nome; "condições" continua sendo o nome dos selos.

Regras já decididas pelo dono:

- sem o requisito, a habilidade fica cinza com o motivo ("Falta: polaridade 2, tem 1"), e o mestre pode usar mesmo assim;
- os requisitos montam grupos "todos estes" e "um destes";
- o requisito de recurso pode só exigir ou também gastar (marcado em cada um);
- o aliado aceita o pedido na tela dele (NPC: o mestre aceita);
- a evolução vira a versão super/overload até ser usada uma vez;
- o que não dá para conferir sozinho vira requisito personalizado, com uma caixa "Cumpriu?".

Cada tipo diz se o app confere sozinho (auto), se pergunta a alguém (pergunta) ou se é só declarado (caixa). Quase todo tipo também tem o contrário ("não ter", "sem").

| A7 | Ter a reação livre (e gasta a reação) | Carregar a polaridade gasta a reação | auto |

Exemplo, o Caça às Bruxas evoluindo:
