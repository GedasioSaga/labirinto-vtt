Protótipo: NPCs no Acervo (o mapa e a ficha são de mentira)
O que dá para fazer aqui
  • Clique no nome de uma ficha (quadradinho) para abrir; no de um token (disco), põe no mapa, como hoje.
  • O + põe no centro do mapa. Ficha que já está no mapa ganha uma cópia, cada token com a própria vida.
  • Arraste uma linha até o mapa, até um token (liga a ficha a ele) ou até uma pasta. Esc desiste.
  • O ⋯ da ficha: abrir, pôr no mapa, fazer cópia, mover de pasta, apagar. Shift+F10 abre pelo teclado.
  • Setas andam na árvore; → e ← abrem e fecham; uma letra pula para o nome. / vai à busca. Ctrl+Z tira o último token posto.
